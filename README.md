# Sebastián Álvarez Delfín — Portafolio

Concept Artist & Visual Development Artist · Ciudad de México

Environment Design, Keyframe Illustration y Character Development para animación y videojuegos.

**Sitio:** https://sebastianalvarezdelfin.github.io/portafolio/

- ArtStation: https://www.artstation.com/ssebasalvarez
- Instagram: https://www.instagram.com/ssebartt
- Email: salvarezdelfin@gmail.com

Sitio estático (un solo `index.html` + `img/`). Para agregar un proyecto o personaje: sube las imágenes a `img/` (cada una como `nombre.jpg` y `nombre-sm.jpg`) y copia una entrada del arreglo `PROJECTS` en `index.html`. Arriba de `PROJECTS` hay una guía con cada campo, cuáles son obligatorios y un ejemplo. Si falta un dato, la consola del navegador lo avisa.
